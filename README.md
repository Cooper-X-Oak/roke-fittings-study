# ROKE fittings — frontend study mirror

Unofficial, non-commercial static mirror of the public frontend at
<https://www.roke-fittings.ru/>, preserved for frontend implementation study.

Live educational preview:

<https://cooper-x-oak.github.io/roke-fittings-study/>

The deployable GitHub Pages artifact is stored in `docs/`. It includes the
public HTML, CSS, JavaScript, fonts, images, AVIF animation frames, videos,
PDFs, ZIP files, and GLB models needed by the static frontend.

Server-side Bitrix/PHP forms, AJAX endpoints, analytics, databases, and
user-data collection are intentionally not implemented.
