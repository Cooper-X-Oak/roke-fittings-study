# ROKE fittings — 中文前端学习镜像

这是 <https://www.roke-fittings.ru/> 公共前端的非官方、非商业静态学习镜像。
页面界面已本地化为简体中文，并保留原站布局、素材和首页滚动拆解动画。

Live educational preview:

<https://cooper-x-oak.github.io/roke-fittings-study/>

可部署的 GitHub Pages 文件位于 `docs/`，包含静态前端所需的 HTML、CSS、
JavaScript、字体、图片、AVIF 动画帧、视频、PDF、ZIP 和 GLB 模型。

服务端 Bitrix/PHP 表单、AJAX 接口、统计分析、数据库和用户数据收集功能均未实现。

复用任何原站素材前，请先阅读 [DISCLAIMER.md](DISCLAIMER.md)。
