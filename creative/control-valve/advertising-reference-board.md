# 广告参考板：一个动作成为一个产品命题

本参考板区分两类证据：

- 商业影片案例决定叙事、镜头、灯光、转场和信息释放方法；
- 工程资料只约束结构名称与事实边界，不负责发明广告镜头。

参考只授权方法，不迁移品牌、功能、性能、工况或工程结论。

## 1. ROKE 首页 240 帧：连接动作就是品牌命题

- 本地一手证据：
  `docs/local/templates/roke/assets/js/animations.homefbd5.js` 中的
  `frames1_avif_new`，共 240 帧，并由滚动进度直接映射。
- 观察到的段落：
  1. 零件沿同一连接轴保持拆分；
  2. 零件依次向中心汇聚；
  3. 完整接头建立；
  4. 产品只做一次有限英雄旋转并稳定。
- 叙事命题：`部件存在 → 连接发生 → 产品成立 → 品牌被记住`。
- 可迁移方法：用一个具有产品意义的连续状态变化统领全片；保持稳定轴线、
  背景、尺度关系和光线世界；让最终英雄镜头成为动作的结论。
- 不迁移：ROKE 接头的装配方向、品牌承诺、材质或零件关系。

## 2. ROKE 多阀组序列：复杂度通过阶段汇聚被理解

- 本地一手证据：同一脚本中的 `frames3_avif`，共 170 帧。
- 观察到的段落：组件不是同时爆炸，而是逐次加入，形成更大的完整阀组，
  随后转向可读的正面并稳定。
- 可迁移方法：分阶段控制部件进入，避免同时移动全部节点；每一步都改变
  观众对整体的理解。
- 不迁移：具体阀组拓扑、装配工序或产品用途。

## 3. Honda Accord《Cog》：前一个动作必然触发下一个

- 一手来源：<https://wklondon.com/work/cog/>
- 叙事命题：用真实汽车零件构成精密链式反应，使 Honda 的工程精度成为
  可以观看的因果过程。
- 可迁移方法：每一段从上一段的结果开始；零件是叙事角色，不是零件目录；
  完整产品是所有前序动作的必然结论。
- 不迁移：复杂连锁机关、实拍语法或 Honda 品牌表达。

## 4. FutureDeluxe × Peloton：高级运镜必须有视觉母题

- 一手来源：<https://futuredeluxe.com/work/peloton>
- 叙事命题：扫描灯光代表 Peloton IQ，微距负责材质，drone-inspired
  sweep 负责尺度和发现感。
- 可迁移方法：灯光和相机必须解释同一个产品观念；宏观到整体的尺度转换
  必须带来新认知。
- 当前决定：不采用无目标无人机穿越。只有当路径、入口、出口和揭示对象
  均由阀门结构支持时，才允许后续 Animatic 评估一次低速短穿越。

## 5. FutureDeluxe × Huawei Mate 70：一个形态贯穿全片

- 一手来源：<https://futuredeluxe.com/work/huawei-mate-70>
- 叙事命题：丝线编织景观呼应手机背板的金属丝纹，让场景、材质和转场
  使用同一个视觉母题。
- 可迁移方法：从当前阀门自身提取母题。本项目选择中央机械轴和三级重复
  轮廓，不引入与产品无关的抽象场景。
- 不迁移：丝线、山水意象、手机材质与品牌语气。

## 6. Lightshape × Pinion MGU：按认知顺序释放完整形态

- 一手来源：<https://www.lightshape.net/en/projects/pinion-mgu-cgi>
- 叙事命题：预告阶段只用光边暗示形态，正式阶段再以爆炸视图和动画解释
  复杂电机变速单元。
- 可迁移方法：先让精密核心成为悬念，再逐步扩大到完整产品；局部和完整
  不是两支镜头，而是同一信息释放过程。
- 不迁移：MGU 功能、爆炸关系或发布节奏。

## 选择结论

当前影片只采用一条母题：

`精密核心 → 层级归位 → 阀体闭合 → 整机成立 → 英雄确认`

连续性来自中央机械轴、产品状态接力和同一光线世界，不靠黑场、强制换轴、
高速 FPV 或五套互不相关的镜头语法。
