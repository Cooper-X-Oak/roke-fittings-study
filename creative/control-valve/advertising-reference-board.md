# 广告参考板：力如何变成控制

本参考板只提取信息顺序、镜头动机、灯光和转场方法，不移植参考产品的品牌、
结构结论或性能声明。

## 1. Emerson Fisher GX：从气源到行程

- 一手来源：<https://www.emerson.com/is/content/emerson/en/final-control/flow-controls/documents/fisher-gx-control-valve-actuator-system-d103171x012.pdf>
- 叙事命题：执行器不是装饰，它把控制信号转换为阀杆行程。
- 可迁移方法：先建立执行器，再沿垂直轴向下追踪推杆；让外部输入与内部动作形成明确因果。
- 镜头语言：高位建立、轴向下潜、在支架或法兰遮挡中切入内部。
- 限制：Fisher GX 的结构与本 STEP 不同，不能迁移其气路、失效方向或产品性能。

## 2. Flowserve Valtek Multi-Z：阶段化内件

- 一手来源：<https://www.flowserve.com/sites/default/files/dam/documents/KMENBR1632_EN_A4.pdf>
- 叙事命题：多级内件的价值来自“阶段”本身，而不是一次性展示一堆零件。
- 可迁移方法：镜头依次跨越阀笼 1、2、3；每级只点亮一个结构边缘，形成节拍清楚的递进。
- 镜头语言：低速微距推进、短暂停顿、窄景深焦点迁移、阶段式光脉冲。
- 限制：资料中的压力曲线和抗气蚀结论不适用于本模型；Animatic 中的流光仅用于指示观察路径。

## 3. SAMSON Series 250：整机、执行器、阀体、内件的信息层级

- 一手来源：<https://www.samson.de/document/t80710en.pdf>
- 叙事命题：先让观众认出完整工业设备，再解释执行器、阀体和内件的关系。
- 可迁移方法：英雄轮廓先于拆解；剖视和爆炸都必须回到完整装配，避免把产品讲成零件目录。
- 镜头语言：低角度三分之四英雄构图、硬质轮廓光、局部切面、最终稳定定格。
- 限制：SAMSON 的材料、应用与性能陈述不能迁移。

## 选择原则

组合三种方法形成一个因果链：

`外部气动权威感 → 线性驱动力 → 串级内件 → 六组构成 → 完整产品`

“无人机穿越”只用于阀杆轴与串级内件之间的连续空间，不做无目的高速飞行；
唯一隐藏切换必须发生在执行器支架或法兰充满画面的遮挡帧中。
