# 五镜头脚本：秩序成为控制

## 导演命题

这不是一次“钻进模型内部”的技术炫技，而是一段让观众始终知道自己
正在看什么的工业产品影片。创意方向是**克制的工业权威**：稳定地平线、
外部观察位置、石墨与冷钢主色、单一铜色焦点、缓慢单向运动和清楚停顿。
该方向是本项目的镜头选择，不冒充未提供的企业品牌规范。

全片 16 秒、30fps、480 帧。五镜头各占 96 帧，每镜最后 24 帧保持
理解停顿。相机 roll 始终为 0，不使用黑场、遮挡隐藏剪辑、瞬移或内部
FPV 穿越。

## 01 — Product Authority / 秩序先于动作

- 范围：0–95 帧。
- 叙事问题：这是什么产品？
- 观众所得：先记住完整轮廓、纵向机械主轴和法兰方向。
- 构图：完整产品位于画面中央偏右；左侧文案保持安静，不与模型争夺尺度。
- 相机：从远景做一次很短的单向 dolly-in；roll 为 0，FOV 从 32° 收到
  31°。
- 产品：保持完整原始装配关系。
- 灯光：冷钢轮廓光定义外形，暖白主光缓慢增加；不从黑场显影。
- 节奏：48 帧推进、24 帧减速、24 帧静止。
- 转场：沿同一外部视角把观察中心上移到机械轴线，无切换。
- 文案：`秩序，先于动作 / 先看清整机，再理解内部。`

## 02 — Axial Command / 一条轴线传递动作

- 范围：96–191 帧。
- 叙事问题：外部动作如何抵达内部？
- 观众所得：执行器、推杆与阀芯保持在同一个观察方向。
- 构图：保留阀体、执行机构和完整外轮廓；内部件不会脱离空间参照。
- 相机：只做外部缓慢靠近和小幅目标点抬升，不进入模型。
- 产品：阀体透明度降到 0.52，推杆做 0.16 的可逆轴向示意。
- 灯光：铜色只锁定中心传递轴，其余系统保持冷钢色。
- 节奏：48 帧解释动作、24 帧减速、24 帧静止。
- 转场：保持相同外部相机位置，继续降低阀体不透明度。
- 文案：`一条轴线，传递动作 / 执行器、推杆与阀芯，始终保持在同一观察方向。`
- 事实边界：轴向示意不代表开、关或故障安全方向。

## 03 — Cascade Revealed / 核心结构逐级显现

- 范围：192–287 帧。
- 叙事问题：控制核心由什么构成？
- 观众所得：串级阀芯与三级命名阀笼处于阀体内部同一轴线上。
- 构图：相机仍在产品外部；半透明阀体持续提供位置和尺度参照。
- 相机：小幅单向 dolly-in；距离目标始终大于 6 个归一化单位，FOV
  只在 30–31° 变化。
- 产品：阀体透明度降到 0.2；阀芯与阀笼不拆散，只按三拍增强铜金色焦点。
- 灯光：不画流体路径，不制造“能量穿梭”。
- 节奏：48 帧逐级显现、24 帧减速、24 帧静止。
- 转场：相机沿原路径缓慢后撤，内部透明度开始恢复。
- 文案：`核心结构，逐级显现 / 外壳退为参照，串级阀芯与三级阀笼仍处在完整空间中。`

## 04 — Systems in Order / 六个系统各在其位

- 范围：288–383 帧。
- 叙事问题：复杂装配如何被理解？
- 观众所得：六组各有职责，但从未失去整体秩序。
- 构图：完整产品仍是中心锚点；系统仅做有限、方向明确的分离。
- 相机：缓慢外移，地平线和视角方向保持不变。
- 产品：最大 explode 仅 0.55，并配合缩短后的组偏移；不把紧固件拆散。
- 灯光：石墨、冷钢和单一铜色焦点保持一致，青色密封组降为辅助。
- 节奏：48 帧展开、24 帧减速、24 帧静止。
- 转场：各系统沿原路径直接归位，不先加速、不回弹。
- 文案：`六个系统，各在其位 / 有限分离说明职责，不打散产品秩序。`
- 事实边界：分离顺序是视觉说明，不是制造或维修程序。

## 05 — Product Resolved / 理解之后仍是整体

- 范围：384–479 帧。
- 叙事问题：解释完内部之后，观众应该记住什么？
- 观众所得：记住完整产品，而不是漂浮的零件。
- 构图：回到完整三分之四英雄视图。
- 相机：前 24 帧只做一次轻微归位；408–479 帧完全锁定。
- 产品：全部组偏移、透明度、阀芯位移和强调归零。
- 灯光：暖白主光与冷钢轮廓光稳定平衡，铜色只留下轻微识别。
- 节奏：24 帧归位，72 帧稳定英雄保持。
- 文案：`理解之后，仍是整体 / DN80 CL2500 气动串级式装配体。`

## 舒适度硬约束

- 黑场和遮挡覆盖上限：0.01；当前脚本为 0。
- 相机 roll：全帧 0°。
- 相机至目标最小距离：6。
- FOV 总范围不超过 3°。
- 相邻 canonical frame 的相机位移不超过 0.08。
- 每镜最后 24 帧的相机、产品和灯光状态完全一致。
- 最后 72 帧为稳定英雄终帧。
