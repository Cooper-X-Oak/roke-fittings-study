# 五镜头分镜脚本：命令成为精密动作

## 影片命题

**控制不是一个瞬间，而是一条被结构组织过的机械路径。**

观众不需要先知道阀门术语。影片只带他完成一条认知链：

`起点 → 路径 → 核心 → 系统 → 产品`

五镜头不是五次相似的产品旋转，也不是一条伪装成“连续”的漫长绕飞。
每次改变景别、机位或观察轴，都必须回答一个新的产品问题。连续性由中央
机械轴、圆形法兰、重复的阀笼轮廓和有动机的匹配剪辑建立，不依赖黑场。

建议脚本时长约 20 秒。时长只是导演节奏，不在本阶段转换为相机帧或运行时
参数。

## 01 — Actuator Origin / 动作从哪里开始

### 叙事任务

- 叙事问题：观众第一眼应该从哪里进入这台复杂设备？
- 观众所得：先认识位于产品上方的气动执行器，它是整条纵向机械观察路径
  的起点。
- 视觉主语：执行器外壳与其下方第一次显露的完整产品。

### 分镜

- 建议时长：3.2 秒。
- 起始状态：不是全景。画面以执行器金属边缘和圆形轮廓的极近特写冷开场，
  观众暂时不知道整体尺度。
- 可见动作：一条冷白轮廓光横向掠过金属边缘；相机随即快速但平滑地撤离，
  阀体、支架和下方法兰依次进入画面。
- 结束状态：完整产品第一次被看清，执行器仍位于构图顶部，中央机械轴已经
  成为明显的纵向视觉线索。
- 景别与构图：`极近特写 → 完整中远景`；从画面右上三分之一撤到产品中央
  偏右的纵向构图。
- 相机：反向 macro dolly-out 加一次不超过 18° 的轻微下降俯仰；无环绕、
  无 roll。
- 灯光：先只给金属轮廓，撤离过程中依次建立执行器、支架、阀体三层亮度；
  不从纯黑中显影产品。
- 页面布局：第一秒只有小号章节字；完整产品出现后，标题在左侧落位。
- 屏幕文案：
  - 眉题：`01 / ORIGIN`
  - 标题：`动作，从最高处开始。`
  - 正文：`先找到执行器，再沿一条轴线理解整台设备。`
- 节奏：0.6 秒辨认纹理，1.5 秒快速撤离，0.7 秒减速，0.4 秒理解停顿。
- 入场：首帧海报直接使用同一极近特写，不做黑场。
- 出场：执行器顶面的圆形轮廓居中，作为下一镜俯视圆形构图的匹配剪辑。
- 理解停顿：完整产品和中央轴至少稳定 0.4 秒。
- 真实性边界：执行器名称来自 STEP；本镜不表现气源、控制信号、作用方向
  或故障安全逻辑。

## 02 — Axis in Motion / 一条轴线如何传递动作

### 叙事任务

- 叙事问题：执行器与内部阀芯之间有什么可见联系？
- 观众所得：执行器、推杆、串级式阀芯沿同一条纵向机械轴组织。
- 视觉主语：从执行器中心延伸到阀芯的中央轴。

### 分镜

- 建议时长：3.8 秒。
- 起始状态：通过圆形匹配剪辑进入俯视轴向构图；执行器顶面成为一组同心圆，
  中央轴位于画面正中。
- 可见动作：相机像吊臂一样沿产品外部垂直下降；执行器外壳逐渐转为半透明，
  推杆以极小幅度做一次轴向示意，镜头沿这条线索抵达支架和上盖。
- 结束状态：相机停在支架上方的高位中景，执行器、推杆和阀芯仍能在同一
  构图内被追踪。
- 景别与构图：`俯视全景 → 高位轴向中景`；强中央构图，与第一镜的斜侧
  构图形成明确变化。
- 相机：俯视轴向 crane-down；路径接近平行于机械轴，但始终位于几何外部，
  不穿进狭窄内腔。
- 灯光：单一铜色光只沿推杆和阀芯建立视觉接力；外围壳体保持冷钢色。
- 页面布局：文字由左侧切换到右上角，让中央轴保持无障碍阅读。
- 屏幕文案：
  - 眉题：`02 / TRANSMISSION`
  - 标题：`一条轴线，把意图变成动作。`
  - 正文：`执行器、推杆与阀芯，共享同一条机械路径。`
- 节奏：0.5 秒匹配建立方向，2.0 秒轴向下降，0.7 秒推杆示意，0.6 秒停顿。
- 入场：执行器圆形轮廓与上一镜执行器顶面做匹配剪辑，不改变圆心位置。
- 出场：上盖或法兰边缘横向掠过画面，形成一次有形几何擦镜；擦镜只占很短
  时间，不演变为黑幕。
- 理解停顿：中央轴、执行器和阀芯关系稳定 0.6 秒。
- 真实性边界：轴向位移只说明可见机械关系，不定义打开、关闭或失效方向。

## 03 — Cascade Precision / 层级藏在内部

### 叙事任务

- 叙事问题：这条机械轴抵达内部后，观众真正需要看清什么？
- 观众所得：串级式阀芯、阀笼 1/2/3 与阀座沿同一轴线形成明确的结构层级。
- 视觉主语：串级式阀芯和三级命名阀笼。

### 分镜

- 建议时长：4.5 秒。
- 起始状态：几何擦镜之后，观察轴旋转 90°，切入侧向剖面微距。阀体仍以
  低透明度轮廓保留，不把内部件变成失去位置的漂浮零件。
- 可见动作：相机不再前后推进，而是从左向右平稳横移；焦点依次落在阀芯、
  阀笼 1、阀笼 2、阀笼 3 和阀座的重复轮廓上。每次焦点接力都由局部光线
  完成，不画流体或能量路径。
- 结束状态：横移停止，阀芯与三级阀笼同时处于可辨认范围，外壳轮廓仍标明
  它们位于阀体内部。
- 景别与构图：`侧向剖面微距`；主体横向占据画面中央，与前两镜纵向构图
  形成最大方向变化。
- 相机：侧向 macro truck，几乎不改变距离；用焦点迁移制造层级，不用相机
  钻入制造刺激。
- 灯光：低饱和铜色标记阀芯，暖金色依次接力三级阀笼，阀体轮廓保持冷灰。
- 页面布局：标题缩到左下角，结构名称以很小的技术标注贴近对应轮廓，
  不出现大段说明。
- 屏幕文案：
  - 眉题：`03 / PRECISION`
  - 标题：`控制的层级，藏在内部。`
  - 正文：`串级式阀芯与三级阀笼，在同一轴线上逐层组织。`
- 节奏：0.5 秒建立剖面，2.4 秒横移与三次焦点接力，0.6 秒合并视野，
  1.0 秒辨认停顿。
- 入场：由上一镜法兰边缘完成几何擦镜，并在切后立即保留相同中央轴高度。
- 出场：三级阀笼的重复圆形轮廓冻结为图形节拍，再扩展为下一镜六系统的
  正交轴测排布。
- 理解停顿：阀芯、三级阀笼与外壳参照同时稳定 1.0 秒。
- 真实性边界：只报告 STEP 中的串级式阀芯、阀笼 1/2/3 和阀座标签；
  不解释压降、介质路径、噪声、气蚀或性能结果。

## 04 — Six Systems, One Axis / 复杂如何被组织

### 叙事任务

- 叙事问题：看清核心之后，如何理解整台复杂装配？
- 观众所得：商业镜头资产把复杂 CAD 组织成六个观察系统，而不是六件独立
  产品或几百个散乱零件。
- 视觉主语：围绕中央机械轴展开的六个语义组。

### 分镜

- 建议时长：4.0 秒。
- 起始状态：重复的阀笼圆形通过匹配剪辑变成正交轴测视图中的系统定位环；
  相机从微距直接切到清晰、近似正交的全产品系统图。
- 可见动作：六个系统不同时爆炸。先固定中央阀芯轴，再让执行器向上、阀笼
  向下、密封与支撑向侧后方、生产细节向侧前方依次离开原位；每组只有一次
  短距离、有方向的运动。
- 结束状态：六组在中央轴周围形成可读层级，完整产品的原始纵向轮廓仍可被
  观众在脑中复原。
- 景别与构图：`正交轴测全景`；产品由单体构图变为系统图构图。
- 相机：固定正交感机位加一次 24° 的缓慢弧形侧移，用轻微视差说明前后
  层级；不持续绕产品旋转。
- 灯光：六组保持统一石墨与冷钢体系，只用铜色维持中央轴；不使用六种高
  饱和颜色把产品变成教学玩具。
- 页面布局：标题位于左侧；右侧用六条短横线标注组名，不出现零件级清单。
- 屏幕文案：
  - 眉题：`04 / SYSTEM`
  - 标题：`六组，不是六件。`
  - 正文：`它们围绕同一条机械轴，被组织成一台完整设备。`
- 节奏：0.4 秒匹配建立系统图，2.0 秒分层展开，0.8 秒弧形侧移，
  0.8 秒阅读停顿。
- 入场：阀笼圆形轮廓与系统定位环做匹配剪辑。
- 出场：中央铜色轴保持不动，外围六组沿原路径同时开始归位；由中央轴把
  下一镜接住。
- 理解停顿：六组位置和标签稳定 0.8 秒。
- 真实性边界：六组是商业镜头的语义组织，不等于 BOM、制造工序、维修步骤
  或功能系统认证。

## 05 — Complexity Resolved / 为什么最终仍是一台产品

### 叙事任务

- 叙事问题：解释了内部和系统之后，观众最后应该记住什么？
- 观众所得：复杂结构最终被收束为一个完整、可识别的工业产品身份。
- 视觉主语：完成归位的 DN80 CL2500 气动串级式调节阀装配体。

### 分镜

- 建议时长：4.5 秒。
- 起始状态：中央铜色轴保持锁定，六个系统从上一镜的系统图位置沿原路径
  归位。
- 可见动作：归位完成时不立刻停住；相机从正交高位缓慢下降到低机位三分
  之四英雄视角，并只绕产品完成一次约 32° 的短弧。灯光从技术图解状态
  收束成完整产品轮廓。
- 结束状态：产品占据画面中央偏右，法兰方向、执行器、阀体和内部铜色焦点
  都能被记住；最后保持稳定，不再追加 CTA 或技术表格。
- 景别与构图：`系统全景 → 低机位英雄中远景`；用相机高度变化而不是继续
  拆解制造结尾。
- 相机：缓慢 pedestal-down 与一次有限 32° hero arc，最后完全锁定；无
  roll、无回弹。
- 灯光：技术标注依次退出，暖白主光建立产品正面，冷色轮廓光勾勒法兰和
  执行器；铜色只保留极弱的内部记忆点。
- 页面布局：六组标签消失，最终标题重新回到左侧大留白区域。
- 屏幕文案：
  - 眉题：`05 / RESOLUTION`
  - 标题：`复杂，被收进整体。`
  - 正文：`DN80 CL2500 气动串级式调节阀。`
- 节奏：1.2 秒归位，1.4 秒下降与短弧，0.3 秒灯光收束，1.6 秒英雄停顿。
- 入场：中央机械轴跨镜保持位置，外围系统沿原路径归位。
- 出场：无黑场、无二次运动；稳定英雄画面自然结束。
- 理解停顿：最终完整产品至少稳定 1.6 秒。
- 真实性边界：终帧只确认源文件名称、产品类型和可见装配关系，不附带规格
  性能、工况、认证或品牌承诺。

## 五镜头差异检查

| 镜头 | 主要景别 | 观察轴 | 相机主动作 | 产品主动作 | 转场装置 |
| --- | --- | --- | --- | --- | --- |
| 01 | 极近特写到完整中远景 | 斜侧 | 快速撤离 | 完整产品显露 | 执行器圆形匹配剪辑 |
| 02 | 俯视轴向中景 | 纵向 | 外部 crane-down | 外壳透明、推杆微移 | 法兰几何擦镜 |
| 03 | 剖面微距 | 横向 | macro truck + 焦点接力 | 内件保持装配 | 阀笼圆形匹配剪辑 |
| 04 | 正交轴测全景 | 轴测 | 24° 短弧侧移 | 六组顺序分层 | 中央轴位置接力 |
| 05 | 低机位英雄中远景 | 斜侧低位 | pedestal-down + 32° 短弧 | 六组归位 | 稳定英雄结束 |

五镜头变化的判断标准不是“相机走了多远”，而是观众能否在每一镜立刻说出：
现在看的是起点、路径、核心、系统，还是最终产品。

## 本阶段停止条件

当前交付只到分镜脚本。以下内容明确不在本阶段执行：

- 不生成 canonical camera path；
- 不生成灰模 Animatic；
- 不修改当前 WebGL；
- 不修改 GLB、材质、首帧海报或公开页面；
- 不自动确认或释放实现。
