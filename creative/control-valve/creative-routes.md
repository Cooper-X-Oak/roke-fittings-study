# 候选创意路线

## 路线 A：力如何变成控制（选择）

- 核心命题：从外部气动执行器开始，沿一条垂直因果轴进入串级内件，解释整机为何是一个连续系统。
- 观众带走的认知：这不是“阀体加气缸”的拼装物；外部行程与内部串级结构是一条动作链。
- 五拍：整机权威感 → 指令下行 → 进入串级核心 → 六组系统展开 → 权威感回收。
- 模型适配：STEP 明确提供气缸、活塞、推杆、串级阀芯、三级阀笼与阀座命名。
- 风险：不能把路径光带解释为真实 CFD；不能猜测失效方向。

## 路线 B：流体的地下航行

- 核心命题：观众作为一个微型观察者，从阀体入口穿入并发现多级内件。
- 五拍：入口定向 → 内腔穿越 → 阀笼递进 → 阀芯改变通道 → 从出口冲出。
- 模型适配：适合强调内部结构，镜头冲击力强。
- 风险：STEP 尚未证明入口到出口的完整可穿越空腔；容易把视觉流线误读成流体仿真，也会弱化执行器。
- 决定：不选为主线，只把短距离“轴向下潜”吸收到路线 A。

## 路线 C：服务顺序的精密装配

- 核心命题：把产品拆成可理解的维护层级，再按轴线回装。
- 五拍：整机 → 紧固件释放 → 执行器抬升 → 内件抽出 → 回装。
- 模型适配：装配层级完整，适合技术培训。
- 风险：用户要的是商业叙事而非维修教程；真实维护顺序没有被 STEP 证明。
- 决定：不选。只保留“分组爆炸后回收”的构成解释，不声称维护顺序。

## 选择结论

路线 A 在产品事实、商业节奏和专业运镜之间最平衡。它让所有镜头都服务一个问题：
外部驱动力如何抵达内部串级结构。路线 B 提供短暂穿越感，路线 C 提供最后的分组解释，
但二者不改变主叙事的信息顺序。
