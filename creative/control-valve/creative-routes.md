# 候选创意路线：从重复展示改为因果叙事

## 本轮问题定义

当前版本虽然分成五章，但五章基本都使用同一套外部三分之四机位、轻微
dolly、透明度变化和静止停顿。标题发生变化，镜头语法却没有变化，因此
观众看不到“为什么现在要看这里”，也无法把五章组织成一个产品认知过程。

本轮不修改 Animatic 或运行时，只选择新的叙事路线并完成五镜头脚本。

## 路线 A：命令成为精密动作（选择）

- 核心命题：控制不是一个瞬间，而是一条被产品结构组织过的机械路径。
- 认知顺序：起点 → 路径 → 核心 → 系统 → 产品。
- 五拍：
  1. 从执行器极近特写突然撤出，找到动作起点；
  2. 切到俯视轴向，沿执行器—推杆—阀芯的机械轴下降；
  3. 旋转观察轴 90°，进入剖面微距，横向阅读串级阀芯与三级阀笼；
  4. 匹配切入正交轴测系统图，六组沿明确方向分离；
  5. 六组归位，相机下降到低机位英雄视角，收束为完整产品。
- 模型适配：现有六个语义节点、阀体透明度和串级内件足以支持五种不同
  画面语法，不需要新增零件级控制。
- 优点：镜头差异服务于信息顺序；既有广告变化，也能始终回答产品问题。
- 风险：第三镜的剖面微距和第四镜的系统展开需要后续 Animatic 确认遮挡、
  构图和阅读时间，本阶段不得假装已经实现。
- 品牌边界：工业精密感来自导演、灯光和版式选择，不声称来自未提供的
  企业品牌手册。

## 路线 B：结构证词

- 核心命题：产品不需要“表演”，只需像工程证物一样被逐层观察。
- 认知顺序：铭牌与轮廓 → 执行器 → 阀体 → 内件 → 完整装配。
- 五拍：五个几乎静态的正投影与剖视构图，由标签和局部光线完成信息切换。
- 模型适配：现有资产完全足够，实现风险最低。
- 优点：清晰、克制、没有眩晕风险。
- 风险：仍然容易重演当前问题——五章只是同一视角的信息替换，商业影片
  的尺度变化、空间发现和时间张力不足。
- 决定：不选择。仅保留其“一个镜头只证明一件事”和事实边界原则。

## 选择结论

选择路线 A。它不以高速飞行、黑场或无动机绕飞制造刺激，而是让五种
镜头语法分别承担五种认知任务。连续性来自匹配剪辑、重复的中央机械轴和
明确的视觉接力，不要求伪装成一条没有剪辑的长镜头。
