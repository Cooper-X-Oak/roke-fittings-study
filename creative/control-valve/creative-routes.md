# 候选创意路线（Issue #17 修订）

## 观看失败证据

生产版实际观看反馈是“突然黑、难理解、缺少品牌调性、头晕”。脚本审计确认：
旧路线在第 150–151 帧使用 0.98 黑色遮挡隐藏相机瞬移，并把近距离
FPV、roll、FOV 变化、大幅后撤和爆炸集中在相邻段落。技术连续不等于
认知连续。

## 路线 A：秩序成为控制（选择）

- 核心命题：控制感首先来自可理解的秩序；观众始终站在产品外部，先看
  整体，再沿同一方向理解机械轴、串级核心和六个系统。
- 视觉方向：克制的工业权威——稳定地平线、石墨与冷钢、单一铜色焦点、
  缓慢单向运动、明确停顿。
- 五拍：产品权威 → 轴向传递 → 核心显现 → 系统在位 → 产品归一。
- 模型适配：六个语义组和阀体透明度足以解释内部，不需要相机钻入模型。
- 优点：空间方向不丢失；每镜只回答一个问题；技术结构最后回到产品身份。
- 风险：运动更克制，需要依靠构图、灯光和停顿建立高级感。
- 品牌边界：这是本项目的产品电影方向，不声称来自未提供的企业 VI 或
  品牌手册。

## 路线 B：内部穿越

- 核心命题：以微型观察者身份钻入阀体，靠速度和遮挡连接外部与内部。
- 五拍：外观 → 入口 → 穿越 → 内腔 → 冲出。
- 优点：瞬时冲击力强。
- 风险：生产版已经证明它会导致黑场、瞬移感、空间方向丢失和眩晕；
  还容易把视觉路径误读成流体仿真。
- 决定：拒绝。旧路线中的隐藏切换、roll 和内部 FPV 全部退出当前方案。

## 路线 C：静态技术图谱

- 核心命题：相机完全不动，仅通过透明度、标签和六组分离解释结构。
- 五拍：整体 → 轴线 → 内件 → 六组 → 整体。
- 优点：理解成本最低、几乎没有眩晕风险。
- 风险：容易退化成培训图解，缺少商业影片所需的时间节奏和产品气场。
- 决定：不选为主线，但吸收“稳定空间锚点”和“每镜理解停顿”。

## 选择结论

路线 A 是对生产观看失败的直接修正。它保留实时 3D 的透明、分离和灯光
能力，却停止用运镜本身充当叙事。路线 B 的冲击力不足以抵消理解和舒适度
损失；路线 C 的清晰度原则被保留，但不把影片冻结成静态说明书。
