# 候选创意路线：从镜头展示改为产品状态叙事

## 本轮问题定义

上一版虽然定义了五个不同镜头，却把“商业级”误解成观察轴、景别和运镜
必须不断变化。结果是相机在组织影片，产品只是被动接受五种观察方法；
“六个语义组”甚至把资产制作逻辑误当成观众需要理解的产品命题。

ROKE 240 帧序列和专业商业影片案例给出相反证据：先选择一个来自产品的
动作母题，再让相机、灯光、布局和节奏共同维护它。

## 路线 A：精密核心成为整体（选择）

- 核心命题：复杂结构沿一条中央机械轴归于秩序，最终成为完整产品。
- 认知顺序：
  `核心显露 → 层级归位 → 阀体闭合 → 整机成立 → 英雄确认`。
- 五个连续节拍：
  1. 从串级阀芯与三级阀笼的轴向拆分状态发现精密核心；
  2. 内件依次沿中央轴归位，建立重复层级；
  3. 阀体与上盖围绕已经成立的核心闭合；
  4. 支架与气动执行器完成整机纵向关系；
  5. 产品停止装配，只做一次有限英雄旋转并稳定。
- 模型适配：现有六个可控语义节点足以控制内件、阀体和执行器的阶段归位；
  叙事不要求几百个零件独立动画。
- 商业依据：迁移 ROKE 的单轴汇聚和一次英雄收尾，迁移 Honda《Cog》的
  状态因果接力，迁移 Pinion 的“核心悬念到完整产品”信息释放。
- 品牌气质：克制、精密、确定。质感来自材质轮廓、缓急关系和最终停顿，
  不来自暗场、快速横滚或连续绕飞。
- 风险：现有六节点资产能否提供足够清楚的三级内件层级，仍需未来
  Animatic 验证；本阶段不假装已经解决遮挡。

## 路线 B：轴内穿越

- 核心命题：观众沿机械轴进入阀门内部，再从核心穿出并发现整机。
- 优点：尺度变化强，容易制造第一眼冲击。
- 风险：当前模型没有足够可信的内部通道来支持连续 FPV；滚动反向播放会
  放大眩晕、穿模和无动机倒飞；摄影动作容易压过产品认知。
- 决定：不选择。只保留“宏观到整体”的尺度转换，不采用高速内部穿越。

## 路线 C：六系统工程图

- 核心命题：把复杂 CAD 组织为六个可读语义组。
- 优点：实现直接，适合制作说明或技术培训。
- 风险：“六节点”是商业镜头资产策略，不是客户购买或记住产品的理由；
  正交系统图会把商业高潮降格为模型说明。
- 决定：不选择。六节点继续作为制作控制层，不进入屏幕文案和叙事高潮。

## 选择结论

选择路线 A。五个段落是一个连续影片中的五个认知节拍，不要求五种观察轴。
每一段必须从上一段的结束产品状态开始；中央机械轴、世界空间和主要光线
方向保持连续。最终英雄旋转只出现一次。
