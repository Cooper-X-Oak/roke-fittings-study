# Precision Becomes Presence — Virtual FPV 五镜头脚本

总时长：16 秒 / 480 帧 / 30fps

画幅：16:9

预演目标：验证一条连续、可逆、由产品认知驱动的虚拟摄影路径；不验证最终材质精度。

## 全片导演命题

相机不是围着车观看，而是被产品的精密关系“截获”：它先被轮廓吸引，随后穿过接地点进入驾驶空间；当理解建立，镜头从车门突破，让内部关系在身后展开；最后相机与结构同时制动，完整产品成为结论。

连续空间句法：

```text
远距轮廓
  → 前轮外缘
  → 轮辐通道
  → 制动盘遮挡（唯一隐藏切）
  → 方向盘获得
  → 驾驶侧切透走廊
  → 驾驶侧车门出口
  → 外部反弧
  → 系统尾流
  → 闭合
  → 稳定英雄帧
```

## Shot 01 — INTERCEPT / 截获

时间：`00:00.0–00:03.0` / 帧 `000–089` / 归一化 `0.0000–0.1875`

叙事目的：先确认完整产品，再让一个可信机械细节截获视线。

观众认知：这不是无上下文的零件特写；轮圈属于一个完整、低伏、具有方向性的产品。

动作与镜头：

- 从前侧远距轮廓快速接近，前 0.9 秒仍可辨认整车；
- 镜头高度由 2.15m 降至 0.58m，FOV 从 38° 收至 22°；
- 路径沿前翼与轮眉曲线掠向左前轮，不做整车 360° 环绕；
- 横滚由 0°渐进至 -8°，只用于让轮缘成为“入口”。

灯光与布局：

- 远距只保留冷色轮廓；接近轮圈时红色边缘光增强；
- 车身曝光逐步降低，视线集中到轮辐入口；
- 文案在左下，不遮挡前轮。

文案：`01 / INTERCEPT` — 先让轮廓被看见，再让精密把视线截住。

节奏与停顿：

- 0.9 秒辨认整车；
- 1.5 秒加速截获；
- 0.6 秒沿轮缘校准入口，没有静态摆拍式停顿。

转场：轮辐占据构图中心，运动矢量直接进入 Shot 02。

真实性边界：不表达空气动力、极速或制动性能；相机速度只是广告运镜。

## Shot 02 — THREAD / 穿入

时间：`00:03.0–00:05.6` / 帧 `090–167` / 归一化 `0.1875–0.3500`

叙事目的：把接地点变成通往驾驶控制空间的物理入口。

观众认知：外部机械细节与内部控制空间在一条连续路径上，而不是两个互不相干的展示图。

动作与镜头：

- 镜头穿过轮辐，横滚峰值 -10°，这是全片唯一高速穿越；
- 镜头朝制动盘推进，FOV 扩到 42°，制动盘暗面形成自然遮挡；
- 帧 123–124 在 96% 遮挡中完成唯一一次确定性空间重定位；
- 遮挡退出时直接获得方向盘，横滚快速回到 +4°后继续归零；
- 外壳透明度降至 8%，只用于低成本预演内部可读性。

灯光与布局：

- 轮圈使用窄红边缘光；
- 遮挡峰值降低主光；
- 方向盘出现时切换为柔和座舱侧光，不使用能量束。

文案：`02 / THREAD` — 穿过接地点，进入控制发生的地方。

节奏与停顿：

- 1.1 秒穿过轮辐；
- 0.4 秒遮挡与隐藏切；
- 1.1 秒获得方向盘并减速。

转场：方向盘不是 Match Cut，而是穿越后的空间目标；速度下降触发 Shot 03。

真实性边界：隐藏切必须在交付说明中公开；不声称无碰撞真实飞行路径。

## Shot 03 — COCKPIT RUN / 座舱穿越

时间：`00:05.6–00:09.0` / 帧 `168–269` / 归一化 `0.3500–0.5625`

叙事目的：把速度让位给理解，让驾驶空间的组织关系成为全片中段。

观众认知：方向盘、座椅和骨架围绕一个连续的驾驶空间组织。

动作与镜头：

- 相机沿驾驶侧切透走廊缓慢后移，速度约为 Shot 02 的 35%；
- 以低透明外壳依次读取方向盘、座椅和骨架，不穿进被座椅填满的实心体积；
- 焦点距离从 0.70m 缓慢扩到 1.10m；
- 末段沿车身外侧转向驾驶侧车门出口，为突破建立明确去向。

灯光与布局：

- 局部方向盘光扩展为座舱侧光；
- 红色座椅作为第二焦点，外壳保持低透明度；
- 文案保持左下，出口方向保留右侧负空间。

文案：`03 / COCKPIT RUN` — 速度放慢，结构开始围绕驾驶空间组织。

节奏与停顿：

- 1.2 秒确认方向盘和前舱；
- 1.1 秒经过座椅与骨架；
- 1.1 秒转向并锁定车门出口。

转场：车门出口在画面中扩大，镜头加速穿出。

真实性边界：不声称人体工学、舒适性或安全等级；“围绕驾驶空间”是视觉命题。

## Shot 04 — BREAKOUT / 突破

时间：`00:09.0–00:13.0` / 帧 `270–389` / 归一化 `0.5625–0.8125`

叙事目的：把已理解的内部关系释放到完整产品尺度，形成唯一高潮。

观众认知：复杂结构不是随机爆炸；它沿镜头离开产品的轨迹成为可读的系统尾流。

动作与镜头：

- 相机从驾驶侧车门出口突破，横滚短暂升到 +7°；
- 随即转入约 135°外部反弧，镜头方向与零件展开方向相反；
- 四轮、座舱和外壳只按系统组分层，爆炸量峰值 0.62；
- 系统分层发生在镜头身后与侧后方，保持整车轮廓作为空间参照；
- 末段爆炸量回落到 0.28，为制动闭合留出距离。

灯光与布局：

- 从内部解释光切换为外部车身主光；
- 红色车漆在突破后才恢复完整曝光；
- 不叠加技术面板，字幕不与结构尾流争抢。

文案：`04 / BREAKOUT` — 离开座舱，关系沿镜头尾流展开。

节奏与停顿：

- 0.9 秒突破；
- 1.3 秒外部反弧；
- 1.1 秒系统尾流达到峰值；
- 0.7 秒开始制动，不做完整 360°环绕。

转场：相机、横滚、FOV 与爆炸量同时进入减速曲线。

真实性边界：分层是广告叙事关系，不是真实装配、维修或工程依赖顺序。

## Shot 05 — ARREST / 制动定格

时间：`00:13.0–00:16.0` / 帧 `390–479` / 归一化 `0.8125–1.0000`

叙事目的：让运动本身成为结论；所有解释停止后，完整产品才获得存在感。

观众认知：精密不是更多运动，而是所有关系最终准确归位。

动作与镜头：

- 帧 390–408 内，相机进入低机位三分之四英雄构图；
- 横滚归零，FOV 收至 27°，焦点稳定到 6.60m；
- 系统爆炸量从 0.28 归零，外壳恢复完整；
- 帧 408–479 共 72 帧完全稳定，占全片最后 15%；
- 稳定范围内相机、目标、横滚、FOV、焦点、零件和灯光均不再变化。

灯光与布局：

- 单一暖主光定义红色曲面，冷轮廓光分离车顶与后翼；
- 深灰背景和左侧负空间为文案留出呼吸；
- 最终帧可直接作为网页滚动终点。

文案：`05 / ARREST` — 运动停止，精密成为完整的存在感。

节奏与停顿：

- 0.6 秒同步制动与闭合；
- 2.4 秒稳定英雄停顿。

转场：无；终点可无限保持，也可按相同逐帧状态精确反向滚动。

真实性边界：不出现品牌、速度、马力、制造或性能承诺。

## Camera Previs 验收契约

- 480 帧必须各有唯一、确定性的相机与场景状态；
- 相机最大绝对横滚不超过 10°；
- 只有帧 123–124 存在隐藏空间重定位，且由制动盘遮挡；
- 只有 Shot 02 是高速穿越，Shot 03 必须明显减速；
- Shot 04 外部弧线不得完成 360°；
- 帧 408–479 必须逐值完全相同，形成最后 15% 稳定英雄停顿；
- 任意帧按索引直接求值，正向与反向采样必须得到同一状态；
- 逐帧真源为 `camera-previs.json`，而不是视频压缩后的像素。
