# Precision Becomes Presence — 五镜头脚本

总时长：16 秒  
画幅：16:9，1920×1080  
预演目标：验证叙事、构图、镜头、灯光、转场和停顿，不验证最终材质精度。

## Shot 01 — CONTACT / 接地点

时间：`00:00.0–00:02.6`  
归一化区间：`0.000–0.1625`

叙事目的：

从模型最可信的机械细节建立第一印象：精密首先发生在车辆与地面的接触处。

画面：

- 黑灰空间中只出现左前轮圈、制动盘和制动块；
- 红色车身保持在暗部，只留下很弱的轮廓；
- 制动盘边缘出现一次克制的红色反射；
- 镜头沿轮圈外缘做非常小的顺时针弧线。

镜头：

- 微距 / 近景；
- 中长焦感，压缩背景；
- 运动从右下向左上建立后续旋转方向。

灯光：

- 窄冷色轮廓光定义金属圆形；
- 红色反射只用于连接下一镜头，不表达温度或能量。

布局与文案：

```text
01 / CONTACT
精密，从接地点开始。
```

节奏与停顿：

- 0.5 秒暗场进入；
- 1.2 秒建立轮圈与制动结构；
- 0.5 秒保持完整圆形，给 Match Cut 留出读图时间；
- 最后 0.4 秒让圆形占据画面中心。

转场：

轮圈圆形与方向盘圆形进行 Match Cut。

真实性边界：

- 不出现制动力、刹车距离或材料性能声明；
- 不把红色反射解释为热量或能量流。

## Shot 02 — HUMAN CORE / 驾驶核心

时间：`00:02.6–00:05.6`  
归一化区间：`0.1625–0.3500`

叙事目的：

把机械精密与驾驶者所在的空间连接起来。

画面：

- 轮圈圆形切换成方向盘；
- 镜头向后滑动，方向盘、仪表、座椅和座舱骨架依次进入画面；
- 外部车门和机盖只以暗色剪影存在；
- 座椅红色材质第一次出现，但不占满画面。

镜头：

- 从方向盘近景后退到座舱中景；
- 轻微上升，最终能读出座椅和骨架之间的包裹关系；
- 不穿过实心模型表面。

灯光：

- 从方向盘上的局部光扩展为座舱侧光；
- 座椅红色只作为第二层焦点；
- 外壳保持低曝光。

布局与文案：

```text
02 / HUMAN CORE
结构，围绕驾驶空间形成。
```

节奏与停顿：

- Match Cut 后 0.35 秒确认方向盘；
- 1.4 秒后退揭示；
- 0.75 秒保持完整座舱关系；
- 0.5 秒继续拉远进入下一镜头。

转场：

座舱骨架的纵向线条扩展为整车结构轴线。

真实性边界：

- 不声称人体工学、舒适度或安全等级；
- “驾驶核心”是叙事概念，不是工程系统名称。

## Shot 03 — SYSTEM / 系统秩序

时间：`00:05.6–00:09.0`  
归一化区间：`0.3500–0.5625`

叙事目的：

让观众理解复杂结构是有层级的，不是随机散落的零件。

画面：

- 镜头拉到整车三分之四解剖视角；
- 四轮 / 制动层、座舱层、外壳层沿三条清晰轴线分开；
- 每次只有一个系统获得主光，其他系统降低亮度；
- 不让所有 97 个网格独立飞散。

镜头：

- 稳定三分之四全景；
- 只做约 12–18 度的解释性弧线；
- 焦点按“接地点 → 驾驶空间 → 外部形态”移动。

灯光：

- 三次局部光转移；
- 红色车漆仍然受控，黑色机械结构保持可读；
- 背景无技术面板、无大字号装饰。

布局与文案：

```text
03 / SYSTEM
复杂，不等于混乱。
```

节奏与停顿：

- 三个系统各约 0.75 秒；
- 每次光线切换后保留约 0.25 秒理解停顿；
- 最后一拍由外壳边缘开始向中心移动。

转场：

最后被照亮的外壳边缘开始向结构基准汇聚，触发 Shot 04。

真实性边界：

- 系统分类依据节点和可见空间关系；
- 不声称该顺序是制造、维修或工程依赖顺序。

## Shot 04 — CONVERGENCE / 汇聚

时间：`00:09.0–00:13.0`  
归一化区间：`0.5625–0.8125`

叙事目的：

把前面建立的系统认知转成影片高潮：秩序最终形成完整产品。

画面：

- 车轴和四轮先稳定在空间基准；
- 座舱与内部结构随后进入；
- 车门、玻璃、机盖和外部表面最后闭合；
- 每组到位后有一个极短的“锁定”停顿；
- 镜头沿车辆前侧到驾驶侧做一次连续弧线。

镜头：

- 全景三分之四；
- 缓慢弧线与组件汇聚方向相反，增强空间可读性；
- 最后停在低机位前侧销售角度。

灯光：

- 从内部解释光逐渐转为车身表面光；
- 每次锁定产生一次非常短的边缘亮度变化；
- 不使用夸张能量束。

布局与文案：

```text
04 / CONVERGENCE
每一个关系，汇成一个整体。
```

节奏与停顿：

- 轮组与基准：0.9 秒；
- 座舱与内部：1.0 秒；
- 外壳闭合：1.3 秒；
- 最终闭合前停顿 0.35 秒；
- 闭合完成后保持 0.45 秒。

转场：

最后的机盖 / 表面闭合触发完整车身主光。

真实性边界：

- 明确为视觉汇聚顺序；
- 不将其描述为真实生产装配流程。

## Shot 05 — PRESENCE / 存在感

时间：`00:13.0–00:16.0`  
归一化区间：`0.8125–1.0000`

叙事目的：

把技术解释收束成一个稳定、值得等待的产品形象。

画面：

- 所有组件停止；
- 红色车身获得完整主光，黑色结构退入阴影；
- 镜头只保留极小的稳定运动；
- 最后一秒完全静止，形成可用于网页最终状态的英雄帧。

镜头：

- 低机位三分之四全景；
- 相机在前 1.3 秒内完成最后 5–8 度调整；
- 后 1.7 秒稳定。

灯光：

- 单一明确主光扫出车身曲面；
- 轮廓光分离车顶、车门和后翼；
- 背景保持深灰，不使用无依据的品牌环境。

布局与文案：

```text
05 / PRESENCE
精密，最终成为存在感。
```

节奏与停顿：

- 0.8 秒完成主光；
- 0.5 秒完成相机稳定；
- 1.7 秒英雄停顿。

转场：

无继续动作。终点必须可以长时间保持，供网页滚动停止和文案阅读。

真实性边界：

- 不出现品牌、速度、马力或生产承诺；
- 最终句只总结影片的视觉命题。

## 连续性检查

```text
轮圈圆形
  → 方向盘圆形
  → 座舱纵向骨架
  → 整车结构轴线
  → 外壳沿轴线汇聚
  → 完整轮廓和表面光
```

每个镜头的视觉终点都是下一镜头的起点；不存在纯文字切章。
