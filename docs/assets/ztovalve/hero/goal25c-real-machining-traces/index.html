真实加工痕迹样片

这组样片把加工痕迹从 Goal 25-D 的材质分区中单独拆出来，用显式几何痕迹表达车削、拉丝、内孔、螺栓孔、倒角磨亮和珠喷微坑，避免用 procedural shader 直接冒充制造痕。
