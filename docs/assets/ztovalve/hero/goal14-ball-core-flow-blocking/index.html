球心锚定多方向解剖 + 90 度启闭流线 blocking

这版把图册爆炸图转成新的功能动作方向：球体作为稳定核心，零部件向左、右、上、下和环形层级展开； 真实球芯单件做 90 度启闭，阀座保持固定，流线只表达介质通路。它仍是低清 blocking，不生成 240 帧正式序列，不替换首页。

  • 02阀体左右、阀杆向上、下支撑向下，动作方向来自图册结构逻辑。
  • 03只有真实球芯单件做 90 度功能旋转；阀座、密封、支撑件和壳体不跟转。
  • 04流线只表达 flow path，不表达压力、流量、零泄漏或具体介质。

评审重点

看五件事：不锈钢材质是否先成立，球体是否成为稳定中心，多方向离散是否有秩序， 90 度启闭是否只作用于真实球芯单件，阀座是否保持固定，流线是否克制并沿通路穿过。

球心秩序

所有结构动作围绕球体发生，球体是画面锚点和功能锚点。

功能动作

90 度四分之一转只给真实球芯单件，避免把阀座、密封、支撑件、壳体、小五金拍成错误随动件。

真值边界

流线只表达通路，不表达压力、流量、零泄漏、DBB/DIB 或材料性能。

通过条件

材质像真实不锈钢，球体稳定，多方向离散不乱，启闭无明显穿模，流线不过度科幻。

如果通过

进入高清 still lookdev：完整产品、球体核心、多方向解剖三张材质图，再讨论正式帧序列。

仍需客户确认

球孔方向、真实开闭方向、随动组、固定轴是否不得旋转，以及最终是否允许保留流线。
