01 / visual benchmark

画册参考 vs Goal 16 问题

画册固定球阀的真实感来自材质层次，而不是全物体同一种银色。Goal 16 的状态有价值，但材质仍像实时预览。

02 / material split

真实材质分层

不锈钢不再是一个 shader，而是多个 roughness、anisotropy 和反射角色。完整参数见 material-layers.json。

缎面壳体

阀体、阀盖等大体块，保持中灰银质量和宽软高光。

加工切面

法兰、圆环和切面，使用更低粗糙度和条形高光。

抛光球芯

只有真实球芯进入 90 度启闭，阀座不跟随旋转。

深色紧固件

螺栓、螺母、孔洞和暗腔提供黑位和工业尺度。

浅色软密封

阀座/密封圈保持非金属质感，避免被银色淹没。

石墨/填料暗部

填料、垫片和深孔不再是浅灰，而是控制过的暗部。

传动与支撑

阀杆、连接轴、支架用窄高光和加工金属区分。

微倒角与法线

所有 CAD 硬边通过 bevel 和 weighted normals 接住高光。

03 / studio rig

离线摄影棚

完整灯光设置见 studio-lighting.json；它的目标是让金属看见真实灯棚，而不是只看见纯白背景。

大面积 softbox

负责主体可读性和宽高光，避免过硬 CG 阴影。

顶部条形灯

给圆柱、法兰、阀杆和切边制造商业产品高光。

黑卡反射

给不锈钢制造深色反射带，让材质摆脱浅灰塑料感。
