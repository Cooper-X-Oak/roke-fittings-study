  • polishedStainlessBall不锈钢高亮度抛光球体 / mirror polished stainless steel ball.
  • machinedStainless机加工不锈钢零件 / machined stainless steel.

  • softSealPtfePTFE 或浅色软密封视觉 / PTFE or light soft-seat visual treatment.
