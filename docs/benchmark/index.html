ROKE 参考站与 ZTOVALVE 旧站迁移解剖

一边拆 ROKE 的板块、功能和素材门槛，一边盘点正拓旧站已有资产、 品牌现状与缺口；用于后续视觉诊断、迁移建模和客户资料清单对齐。

06 / Client Inputs

客户资料清单

资料清单按迁移优先级拆分：没有这些资料，页面可以做壳，但无法成为可信工业产品官网。

P0 上线必需

  • 1Logo 源文件、品牌色、公司全称和法律信息。
  • 2产品分类与产品 Excel，至少覆盖 8 类和公开 52 条。
  • 3每个产品主图、中文名称、所属分类、新旧 URL 映射。
  • 4地址、电话、传真、邮箱、在线咨询方式。
  • 5公司简介、企业实力、荣誉证书、质量体系原始资料。

P1 销售增强

  • 1产品参数：材质、口径、压力、标准、连接方式、驱动方式。
  • 2型录 PDF、证书 PDF、检测报告、应用行业资料。
  • 3英文产品名和英文详情文案。
  • 4询价表单字段、收件邮箱或 CRM 对接方式。
  • 5搜索/筛选规则：分类、标准、材质、压力、口径。

  • 1高清工厂、设备、检测、仓库和应用场景照片。
  • 2重点产品 CAD、STEP、GLB 或可转 3D 的产品资料。

  • 4可公开的客户案例或行业解决方案。

08 / Diagnosis

迁移风险诊断

这些不是设计偏好，而是会影响报价、周期、验收和上线质量的真实迁移风险。

线上旧站不是权威数据源

详情页和新闻页暴露 SQL 错误；只能当线索，不能当最终内容库。

产品字段不足

公开页主要有标题和图片；缺规格、标准、材质、压力、口径和下载资料。

英文内容不完整

英文入口存在，但抽样出现中文产品名；双语应独立审校。

动态功能需重建

旧搜索返回 403，PHP/点击统计不应迁移；询盘应按新流程实现。

ROKE 视觉依赖高质量素材

没有高清图、PDF、视频或 3D 模型时，只能先做弱化版高端页面。

产品分类基础明确

8 个产品分类和约 52 个公开条目可作为第一版目录骨架。

公司背书可迁移

公司简介、联系方式、荣誉和实力图片可转成现代企业背书模块。

适合先做样板

先完成首页、目录和一个重点产品页，可以快速对齐客户审美和资料缺口。
