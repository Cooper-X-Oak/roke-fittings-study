01 / ROTATE

旋转，不是播放。

同一份几何在 GPU 上实时成像。视角、反射和清漆高光连续变化，不需要为每个角度预先输出一张图。

02 / SEPARATE

每个零件，
都是真的。

车门、车轮、机舱和内饰沿各自空间方向分离。向上滚动时，保存的原始变换会让它们精确回到装配位置。

03 / COMPRESS

2.48 MiB，
保留材质细节。

Draco 压缩几何；KTX2/BasisU 纹理在下载和显存中都保持压缩。当前 GLB 是单文件交付，不依赖运行时第三方模型请求。

04 / UNDERSTAND

低流量，
换取实时自由度。

这就是取舍：网络只传一个压缩样机，浏览器承担实时解码和渲染。适合产品检查、配置器和交互式技术说明。
