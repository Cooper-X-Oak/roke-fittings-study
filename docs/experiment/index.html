01 / VIRTUAL FPV INTERCEPT

让轮廓被精密截住。

先让轮廓被看见，再让精密把视线截住。镜头沿车身轮廓俯冲到前轮，产品叙事从一个可信入口开始。

↓ 向下滚动探索

02 / THREAD

穿过接地点，进入控制。

穿过接地点，进入控制发生的地方。镜头在制动盘遮挡中完成唯一一次隐藏切，方向盘随即成为下一段的视觉目标。

03 / COCKPIT RUN

速度放慢，空间被理解。

速度放慢，结构开始围绕驾驶空间组织。相机在方向盘、座椅和座舱框架之间主动减速，让高速穿越转成清晰的产品认知。

04 / BREAKOUT

突破座舱，系统形成尾流。

离开座舱，关系沿镜头尾流展开。镜头从车门出口加速突破，转入克制的外部反弧，整车轮廓始终提供空间参照。

05 / ARREST

运动停止，存在感出现。

运动停止，精密成为完整的存在感。相机、横滚、视场、灯光和部件同步制动；最后 15% 完全稳定。
